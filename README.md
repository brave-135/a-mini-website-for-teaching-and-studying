# a-mini-website-for-teaching-and-studying
 It is a mini website for teaching and studying, including posting blogs and running small projects online. 
 Computers which run this project(one is the host and the others are customers)must share the same network environment.
 The host computer which run the project must run the Python file "server.py" first, then you can open your browser with"http://localhost:8080/".
